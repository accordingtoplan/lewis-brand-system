One rule, as written in voice.md

Community developer. Never “real estate”.

Why
“We would prefer to never use the phrase ‘real estate’. We think this is an opportunity to instead use ‘community developer’.” Lewis feedback, 11 January 2023.
Where
Every surface, every business. One exception from the voice guide: search optimization.
Instead
community developer, community development

Every rule carries its reason, usually in Lewis’s own words from the 2023 review rounds. Every figure carries its source and date. Where Lewis’s own documents disagree, the system says so and asks, instead of choosing.

Plain text files that any person can open. A version history records each decision and the reason behind it.

04 · Where it runs

On Lewis’s own servers. Private by design.

The recommendation: Lewis runs its own AI workspace, built on open-source software, on servers Lewis controls.

Briefs, drafts, plans and documents stay inside Lewis. Teams sign in with their Lewis accounts. The brand system sits at the center, so every answer starts from it.

The workspace

An open-source chat and agent workspace, such as LibreChat or Open WebUI, installed on Lewis’s servers. One place for every team, with Lewis sign-in and Lewis’s own access rules.

The model

Open models running on the same servers, so nothing leaves Lewis. Where a task needs more, a commercial model such as Claude through Lewis’s own cloud account, where the data stays in that account.

The system

Plain text files at the center of the workspace. The same files work in any tool, so Lewis is never tied to one vendor.

The same system works with any other AI tool a team needs: Claude, ChatGPT, Copilot or the next one. One source behind all of them. A rule changed once reaches every tool with the next update.

07 · Decisions

Seven choices for consistency. Six to make together.

Small choices that keep every document consistent. Each one is confirmed in the first working session, then holds for every document after.

  1. Integrity as the fifth value, with Authenticity, Responsibility, Collaboration and Passion.
  2. One ranking: “one of the nation’s largest privately held community developers”, in that wording only.
  3. No serial comma. AP style, which the voice guide names as its reference, so Lewis reads the way the press prints it.
  4. “Guest Builder” allowed as the trade term for the buyer in land offerings.
  5. The business color leads on a business’s own material. Lewis Blue on group material.
  6. Phase 1, Phase 2, Phase 2A. Figures, AP style.
  7. Business order as on the website: Apartments, Retail Centers, Planned Communities, Office & Industrial, Land Acquisition.

To decide together

  1. The name in use: Lewis Apartments or Lewis Apartment Communities.
  2. One approved sentence for each business.
  3. One tagline for the group. The same line for every business, or none.
  4. The presentation template every team starts from.
  5. The role of the Lewis Commercial logo.
  6. “Together We Build Better.” from the guidelines: a line for use?
